# Лабораторная 1 — базовые объекты конфигурации

[Все работы](../README.md) · [Запуск базы](START.md) · [Следующая работа](Lab2.md)

Пошаговое повторение с промежуточными действиями: [каждый шаг лабораторной 1](WALKTHROUGH.md#лабораторная-1).

## Цель и задание

Освоить метаданные: константы для единичных значений, справочники для списков,
перечисления для фиксированных вариантов и подсистемы для организации интерфейса.
Создать основу «1С:Фактория», сведения об организации, сотрудников и номенклатуру.

## Объекты в проекте

| Объект | Назначение |
| --- | --- |
| Константа ГенеральныйДиректор | Ссылка на сотрудника |
| Константа ИННОрганизация | ИНН, строка длиной 12 |
| Константа ЮридическоеНаименование | Название организации |
| Общая форма ДанныеОрганизации | Совместное редактирование трёх констант |
| Справочник Сотрудники | Фамилия, имя, отчество, дата рождения |
| Справочник СписокНоменклатуры | Иерархический список, синоним «Номенклатура» |
| Перечисление ВидыНоменклатуры | Материал, РасходныйМатериал, Услуга, Товар |
| Перечисление ПроисхожденияНоменклатуры | Импортный и отечественный варианты |
| Подсистема Фактория | Основной раздел интерфейса |

В методичке константа ИНН названа `ИННОрганизации`, а в проекте —
`ИННОрганизация`. При поиске объекта используйте имя из проекта.

## Порядок настройки в Конфигураторе

1. Откройте конфигурацию. В **Общие → Подсистемы** откройте «Фактория».
   В составе подсистемы проверяются объекты, доступные в этом разделе.
2. Откройте **Справочники → Сотрудники → Данные**. Реквизиты Фамилия, Имя,
   Отчество должны хранить строки; по заданию длина каждой — 50.
   ДатаРождения имеет тип Дата с составом «Дата».
3. Здесь же нажмите **Стандартные реквизиты**. Для `Code` задаётся синоним
   «Табельный номер», для `Description` — «Фамилия И.О.».
   Новые реквизиты вместо кода и наименования создавать не нужно.
4. Откройте **Константы → ГенеральныйДиректор**. Тип должен ссылаться на
   справочник Сотрудники, а не быть произвольной строкой.
5. Проверьте остальные константы. ИНН хранится строкой: его не складывают,
   а ведущие нули не должны теряться.
6. Откройте **Общие → Общие формы → ДанныеОрганизации**. Поля привязаны к
   `ConstantsSet.ГенеральныйДиректор`, `ConstantsSet.ИННОрганизация` и
   `ConstantsSet.ЮридическоеНаименование`.
7. В **Перечислениях** откройте оба перечисления и их раздел «Данные»/«Значения».
   Проверьте фиксированные варианты, приведённые выше.
8. Откройте **Справочники → СписокНоменклатуры → Иерархия**.
   Используется иерархия групп и элементов.
9. В **Данные → Стандартные реквизиты** пользовательские подписи задаются
   для кода, наименования и родителя: «Артикул», «Название», «Номенклатурная группа».
10. Дополнительные реквизиты — `ВидНоменклатуры` и `ПроисхождениеНоменклатуры`.
    Их типы — ссылки на соответствующие перечисления.
11. Обновите конфигурацию базы и запустите Предприятие.

## Что заполнить в Предприятии

1. В разделе **Фактория** откройте сотрудников и создайте не менее пяти записей.
2. В каждой заполните ФИО, отдельные части имени и дату рождения.
3. Откройте общую форму данных организации, выберите директора из сотрудников,
   заполните ИНН и юридическое название, сохраните.
4. Откройте номенклатуру. Командой **Создать группу** заведите группы и подгруппы
   по рисунку методички. Сам рисунок является источником точного состава папок.
5. Внутри групп создайте позиции. У каждой укажите название, вид и происхождение.

## Как показать преподавателю

- Общие данные организации редактируются вместе; директор выбирается из справочника.
- В сотрудниках есть минимум пять записей и нужные поля.
- В номенклатуре раскрываются группы и подгруппы.
- При выборе вида доступны четыре значения, при выборе происхождения — два.
- Покажите разницу между программным именем `СписокНоменклатуры` и синонимом «Номенклатура».

## Особенности текущего результата

Отдельной сохранённой формы элемента номенклатуры в `source/Lab6` нет:
используется автогенерируемая форма. Поэтому совпадение вида переключателя
происхождения с рисунком методички не подтверждено. Наличие двух значений
перечисления само по себе не означает отображение круглыми переключателями.
Тестовые сотрудники и папки не входят в CF и проверяются отдельно в базе.

## Что объяснить на защите

Константа хранит одно общее значение, справочник — множество записей.
Перечисление ограничивает выбор заранее заданными значениями. Группы справочника
связаны стандартным реквизитом Родитель. Синоним меняет подпись, но не программное
имя. Подсистема формирует раздел командного интерфейса.
