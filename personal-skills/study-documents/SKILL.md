# Study Documents

Prepare a submission-ready document while preserving the assignment requirements.

1. Read the source material and separate assignment instructions from examples.
2. Preserve facts, formulas, terminology, and the requested structure.
3. Use headings, lists, tables, captions, and page breaks only where they improve readability.
4. Keep citations close to supported claims and never invent sources.
5. When editing an existing file, preserve unrelated content and formatting.
6. Render or preview the finished artifact and check page breaks, clipped text,
   tables, images, headings, and Cyrillic characters.
7. Return the final file and briefly identify any part that still needs manual review.

For a PDF, do not assume extracted text represents its visual layout. Inspect
rendered pages when positioning, forms, diagrams, or typography matters.
