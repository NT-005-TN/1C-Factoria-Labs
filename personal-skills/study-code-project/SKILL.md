# Study Code Project

1. Read the assignment and identify required behavior, constraints, language, and deliverables.
2. Inspect the existing project before changing files. Preserve unrelated work.
3. Choose the smallest structure that keeps source, tests, fixtures, and documentation understandable.
4. Implement the requested behavior without adding unrelated frameworks or features.
5. Document how to install dependencies, run the program, run tests, and reproduce the result.
6. Use small examples that demonstrate the main path and important edge cases.
7. Run relevant formatting, compilation, tests, or validation and report the exact outcome.

Do not claim the project works because files were generated successfully. Verify
observable behavior in proportion to the assignment risk.
