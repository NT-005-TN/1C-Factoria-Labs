# Study Web Project

1. Clarify the page purpose, required content, target devices, and submission format.
2. Reuse the existing stack and design language when editing a project.
3. Implement the smallest complete user flow before decorative enhancements.
4. Use semantic HTML, keyboard-accessible controls, readable contrast, and responsive layout.
5. Keep sample data visibly labeled and do not present placeholders as real results.
6. Test the main interactions, loading states, empty states, and small-screen layout.
7. Provide commands for local launch and a short description of the project structure.

Do not publish or deploy externally unless the user explicitly asks for deployment.
