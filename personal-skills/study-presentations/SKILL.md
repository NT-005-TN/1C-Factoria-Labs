# Study Presentations

Build the deck around what the student must explain, demonstrate, and defend.

1. Identify the audience, time limit, required topics, and evidence available.
2. Create a short narrative: problem, approach, implementation, result, verification, conclusion.
3. Give each slide one main idea and a title that states that idea.
4. Prefer screenshots, diagrams, and small tables to paragraphs of text.
5. Put detailed code only on slides where the exact fragment is discussed.
6. Add concise speaker notes with the explanation and expected questions.
7. Verify that text is readable, elements do not overlap, and the deck works without hidden context.

Do not fabricate screenshots or test results. Label planned or illustrative
content clearly when real evidence is not available.
