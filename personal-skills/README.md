# Универсальные скиллы для учёбы

Этот каталог содержит самостоятельные скиллы для Codex. Они подходят для
учебных и личных проектов и не требуют доступа к внутренним системам Яндекса.

| Скилл | Назначение |
| --- | --- |
| `study-documents` | Word, PDF и проверка оформления |
| `study-presentations` | Презентации и защита работ |
| `study-spreadsheets` | Excel, CSV, расчёты и диаграммы |
| `study-code-project` | Разработка, структура проекта и документация |
| `study-code-review` | Проверка кода, тестов и безопасности |
| `study-notes` | Конспекты и личная база знаний |
| `study-diagrams` | Блок-схемы, процессы и архитектура |
| `study-web-project` | Учебные сайты и веб-приложения |
| `study-surveys` | Анкеты, тесты и формы обратной связи |
| `study-skill-builder` | Создание собственных скиллов |

## Установка

Скопируйте нужную папку целиком в каталог личных скиллов Codex:

```text
~/.codex/skills/<имя-скилла>/SKILL.md
```

После копирования начните новый чат, чтобы Codex перечитал каталог. Скилл можно
вызвать по имени, например: `$study-presentations сделай презентацию для защиты`.

Скиллы описывают рабочий процесс, но не добавляют отсутствующие приложения или
доступы. Для обработки конкретного формата агент должен использовать доступные
в текущем окружении инструменты.
