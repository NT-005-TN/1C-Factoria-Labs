# Study Spreadsheets

1. Inspect sheet names, headers, data types, formulas, and missing values before editing.
2. Preserve the original workbook unless the user explicitly requests replacement.
3. Use formulas for calculations that the reader may need to audit or change.
4. Keep raw data separate from summaries and charts when the workbook is nontrivial.
5. Apply clear number, date, and percentage formats without hiding precision unexpectedly.
6. Validate totals using an independent calculation or a small known example.
7. Preview the workbook and check column widths, wrapped headers, filters, frozen panes, and chart labels.

State assumptions behind calculations. Never silently replace missing values or
change the denominator of a metric.
