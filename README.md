# Лабораторные работы 1С Фактория

В репозитории находятся учебные конфигурации для платформы «1С:Предприятие».

## Файлы

- `Lab1.cf` — исходная конфигурация после первой лабораторной работы.
- `Lab2-progress.cf` — промежуточная версия с заданиями второй лабораторной работы.
- `Lab3-final.cf` — итоговая конфигурация после третьей лабораторной работы.
- `source/` — текстовая выгрузка всех трёх конфигураций для просмотра кода и истории изменений через Git.
- `metadata/Фактория.xml` — описание подсистемы «Фактория».
- `TASKS.md` — формулировки заданий лабораторных №2 и №3.
- `DEMO.md` — порядок запуска и демонстрации лабораторной №3.
- `VALIDATION.md` — результаты автоматической проверки итоговой конфигурации.

## Лабораторная работа 2

Реализованы задания на встроенном языке 1С: сокращение ФИО, расчёт розничной цены, условная логика, работа с массивом и таблицей значений.

## Лабораторная работа 3

Созданы справочники поставщиков и договоров, документы «Заказ поставщику», «Приходная накладная» и «Расходная накладная». Настроены табличные части, отбор номенклатуры, автоматический расчёт сумм и итоги в подвалах таблиц.

Итоговая конфигурация `Lab3-final.cf` проверена средствами конфигуратора 1С: ошибки проверки не обнаружены, структура тестовой базы обновляется успешно.

## Открытие конфигурации

В Конфигураторе выберите **Конфигурация → Загрузить конфигурацию из файла** и укажите нужный файл `.cf`. После загрузки выполните **Конфигурация → Обновить конфигурацию базы данных**.
